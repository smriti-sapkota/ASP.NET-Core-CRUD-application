# CRUD Application

A simple CRUD (Create, Read, Update, Delete) application built using **ASP.NET Core MVC**.

## Tech Stack
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- C#

## Purpose
Learning and practicing ASP.NET Core MVC with database integration.
